# Devops For Developers Project 76

Деплой приложения Redmine с помощью Ansible на облачную инфраструктуру DigitalOcean.

## Приложение

https://daniscoder.online

## Требования

* Ansible
* Make

## Установка зависимостей

```bash
make install
```

## Подготовка серверов

```bash
make setup
```

## Деплой

```bash
make deploy
```
